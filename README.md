# SignalDesk

SignalDesk is a focused publishing workspace for creators and marketing teams. The first slice includes a dashboard, drafts, a weekly content calendar, connected account states, and an interactive multi-platform composer.

## Run locally

Install Node.js 20 or newer, then run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Current scope

The UI uses local state for the first vertical slice. Real OAuth connections, media uploads, platform API publishing, scheduling workers, and persistence are the next product layer.
